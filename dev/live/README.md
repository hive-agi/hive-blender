# hive · geometry — live Blender run

2026-10-07, Blender 5.2 Flatpak GUI on `DISPLAY=:0`; actual Blender PID **649857** (launcher timeout PID 648461). Blender was deliberately left running for Pedro. The installed MCP-for-Blender add-on reported protocol 13 over localhost:9876. Telemetry was disabled via `DISABLE_TELEMETRY=1`, network update checks via `BLENDERMCP_NO_UPDATE_CHECK=1`; no optional provider, Premium, or telemetry commands were sent.

`hive_geometry_3d.clj` drives the catalogued hive-blender socket transport through `service/call` with an installed `CodeGate` and explicit confirmation for each `execute_code`. A dedicated worktree nREPL ran from this directory. Hex-cell positions and golden-angle-derived heights are computed in Clojure. The 91 beveled hexagonal prisms arrived in six successive calls/rings, then amber/transmission material and basalt ground, seven thin Flower-of-Life tori and solar hexagon, then orthographic camera, area light, and material-preview viewport. A screenshot was captured after each stage. Final scene contains 91 slab cells, ground, 7 tori, central sun, camera, and light. The final `dev/live/hive-geometry.png` is the viewport screenshot after camera/material-preview staging.

Measured transport journal for the final/recovery sequence: **25 calls, 164,039 ms cumulative call time** (including one 60,062 ms timeout); GLB export response 1,477,424 bytes / 100 mesh objects, STL export reports 91 slab meshes. Exports: `~/.cache/hive-craft-blender/out/hive-geometry.glb` (1.5 MB, validated glTF binary v2) and `~/.cache/hive-craft-blender/out/hive-geometry-slab.stl` (729 KB); screenshots `stage-1.png` through `stage-5.png` (1156×777). The final camera screenshot is `stage-4.png`, taken after the exports; all five stage captures remain in the output directory.

Gaps / recovery (exact error strings): startup Python expression attempted a nonexistent Scene property and logged `AttributeError: 'Scene' object has no attribute 'blendermcp_telemetry_consent'`; add-on installation, enablement, and auto-start had already succeeded, and telemetry stayed off by environment. One material-preview screenshot returned `{:kind :blender/unknown-outcome, :hint "Timed out after dispatch; do not replay."}` after 60,062 ms; its screenshot file appeared after the timeout. That call was **not replayed**; later the scene was cleared and rebuilt because the first partial sequence still contained the default cube. After the rebuild all five stage screenshots and both exports were verified, and the camera staging was completed without error.

Do not stop Blender when examining the result. To drive a fresh scene, use `cider spawn` in this worktree and `(load-file "dev/live/hive_geometry_3d.clj")` followed by `(future (hive-geometry-3d/run!))`; this clears the current scene and exports to the listed paths, so choose fresh paths for any subsequent run.
